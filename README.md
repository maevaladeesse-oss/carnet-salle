# Carnet de salle

Programme de musculation (haut du corps, 4 ou 5 séances par semaine) avec surcharge progressive automatique.

Application : https://maevaladeesse-oss.github.io/carnet-salle/

Les séances sont enregistrées uniquement sur le téléphone (stockage du navigateur). Utilise l'export de sauvegarde dans l'onglet Progrès.
